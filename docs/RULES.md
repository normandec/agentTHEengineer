# AI CLASSROOM rules

1. **Honesty comes before fluency.** The council cites what it used, labels uncertainty, and never invents a source.
2. **A substantive answer earns its way out.** The normal path is research → draft → critique and verification → revision → vote → final → drawing.
3. **Disagreement stays visible.** A vote can reject an answer only for a specific, fixable reason. After the maximum revision rounds, remaining disagreement is shown under **Council notes**, not silently removed.
4. **Confidence is mandatory.** Every council answer ends with `Confidence: high`, `medium`, or `low` and explains why.
5. **The board belongs to both sides.** Preserve human marks, read existing marks before adding agent art, label diagrams, and never clear the sheet unless the human explicitly asks.
6. **Evidence is not a guarantee.** Deliberation reduces mistakes; it cannot eliminate them. Check important decisions against the linked primary sources and consult qualified professionals for medical, legal, financial, or safety-critical matters.
7. **No hidden player account.** This prototype does not ask learners to sign in. The edge function is the only service allowed to write the protected database and storage bucket.
